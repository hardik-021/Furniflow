# 🪑 Furniflow — Classic Furniture Store

A responsive furniture e-commerce website built with **HTML**, **CSS**, and **JavaScript** using **Bootstrap 5**.

---

## 🌟 Features

- 🔐 **User Authentication** — Register & Login with localStorage
- 🛍️ **Product Catalog** — Browse 30+ furniture items across 6 categories
- 🛒 **Shopping Cart** — Add/Remove items, view total price
- ➕ **Add Furniture** — Dynamically add new products with image URL
- 💾 **Persistent Data** — Cart and products saved via localStorage
- 📱 **Responsive Design** — Works on desktop and mobile

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hardik-021/Furniflow.git
   ```

2. **Open in browser:**
   - Navigate to the `project/` folder
   - Open `project.html` in any browser (Chrome recommended)

3. **Register an account** on the login screen, then **Login** to access the store.

> ⚠️ No server or installation required — it's a fully static website!
